# ✅ Todo List App

A simple and responsive **Todo List** web application that helps users manage their daily tasks efficiently. Built with HTML, CSS, and JavaScript.

---

## 🚀 Features

- ➕ Add new tasks quickly
- ✅ Mark tasks as completed
- 🗑️ Delete individual tasks
- 💾 Persist tasks using Local Storage (tasks remain after page refresh)
- 📱 Responsive design — works on all screen sizes

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Structure & markup |
| CSS3 | Styling & layout |
| JavaScript (ES6+) | Logic & interactivity |

## ⚙️ Getting Started

### Prerequisites

All you need is a modern web browser — no installations required!

### Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/Bhuvaneswaran9361/Todolist.git
   ```

2. **Navigate to the project folder**
   ```bash
   cd Todolist
   ```

3. **Open in your browser**
   ```bash
   open index.html
   ```
   Or simply double-click `index.html` to open it in your default browser.

---

## 🎯 Usage

1. Type a task into the input field
2. Press **Enter** or click the **Add** button to add the task
3. Click on a task to mark it as **completed**
4. Click the **delete** icon to remove a task
5. Your tasks are automatically saved in your browser's Local Storage
